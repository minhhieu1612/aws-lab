Quick AWS EC2 Deployment Commands

# 1. Connect to EC2 (Amazon Linux 2023 or Ubuntu)
ssh -i your-key.pem ec2-user@YOUR_EC2_PUBLIC_IP

# 2. Run with PM2 for 24/7 uptime & auto-restart
sudo npm install -g pm2
pm2 start server.js --name "aws-node-app"
pm2 startup
pm2 save
